# 🚀 Coding Challenges

## Folder Structure

Solutions sourced from online coding-challenge platforms. Each platform lives
in its own sub-folder, and each challenge lives in its own numbered sub-folder.

```
Coding-Challenges/
├── Exercism/     # Challenges from Exercism
├── Leet-Code/    # Challenges from LeetCode
└── README.md
```

| Folder | Description |
| --- | --- |
| [Exercism](Exercism) | Challenges sourced from [Exercism](https://exercism.org). Currently contains the `1-Hello-World` placeholder. |
| [Leet-Code](Leet-Code) | Challenges sourced from [LeetCode](https://leetcode.com). Currently contains `1-Two-Sum`. |

> Note: an earlier version of this README referenced a `Code-Wars` folder, which
> does not exist in the repository. The actual folders are listed above.
