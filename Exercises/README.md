# 🚀 Github Repos New (2026) - Exercises

A sub-folder containing any exercises that were not from coding challenge platforms or interviews.

## Folder Structure

```
Exercises/
├── 1-File_Exercise/                      # File management CLI
├── 2-Sorting_Exercise_Sorting_Program/   # Sorting library
├── 3-Simple_Map_Exercise/                # Classroom attendance map
└── README.md
```

## Contents

| Exercise | Description | Tech |
| --- | --- | --- |
| [1-File_Exercise](1-File_Exercise) | Create, rename, edit, copy and delete `.txt` files between a `source/` and `destination/` folder. | Go |
| [2-Sorting_Exercise_Sorting_Program](2-Sorting_Exercise_Sorting_Program) | A sorting library implementing six classic algorithms on `[]int`. Covered by CI. | Go |
| [3-Simple_Map_Exercise](3-Simple_Map_Exercise) | A `map[string]bool` attendance tracker for a class of students. | Go |

Each exercise is an independent Go module (`go.mod`) and, where present, ships a
`Makefile` with `test` (and sometimes `run` / `bench-test`) targets.
